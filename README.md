# Kaptan

LupuS quick desktop configuration wizard built with Python 3 and PyQt6.

## Requirements

### Build Dependencies

- Python >= 3.14
- `python3-setuptools` & `wheel`
- `python3-qt6` & `python3-pyqt6-sip`
- `qt6-linguist` (`lrelease6` / `lrelease-qt6` / `lrelease`)
- `python3-devel`

### Runtime Dependencies

- Python >= 3.14
- `python3-qt6`
- `python3-pyqt6-sip`

## Installation

To build and install Kaptan on your system, run:

```bash
sudo python3 setup.py install
```

Or install using `pip`:

```bash
sudo pip install .
```
